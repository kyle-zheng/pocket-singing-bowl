# User Guide

Electronic Singing Bowl works offline. The current on-device labels are in Simplified Chinese; the controls below use English descriptions.

## Main controls

| Screen or mode | Gesture | Result |
| --- | --- | --- |
| Home, manual or automatic | Press UP / DOWN | Change the note and theme |
| Manual | Press OK | Play one tone |
| Manual | Hold OK | Start automatic playback with an immediate tone |
| Automatic | Press OK | Pause or resume |
| Automatic | Hold OK | Stop and return to manual standby |
| Home | Double-press OK | Open settings; automatic playback pauses |
| Settings list | Press UP / DOWN | Select a setting |
| Settings list | Press OK | Edit the selected setting |
| Settings list | Hold OK | Return home |
| Editing | Press UP / DOWN | Adjust the value |
| Editing | Press OK | Save the value |
| Editing | Hold OK | Cancel the edit |
| Editing interval or volume | Hold UP / DOWN | Adjust faster; release to stop |

Automatic playback remains paused after leaving settings. Press OK at home to resume it. Changing a theme does not require returning to manual mode.

## Settings

- **Strike interval:** 6–60 seconds, adjusted in one-second steps; default 6 seconds.
- **Automatic duration:** 1, 3, 5, or 10 minutes, or unlimited; default 3 minutes. Unlimited sessions continue until you pause or stop them, or the device runs out of power.
- **Bowl volume:** 0–100% in five-percent steps; default 50%. Zero is persistent mute. The top of the scale uses the application's tuned output ceiling.
- **Automatic sleep:** off by default. When enabled, ten idle minutes trigger a brief backlight fade and then sleep. Active automatic playback does not sleep. A completed timed session starts a fresh idle period.

Preferences are saved after a short quiet period. On restart, the app uses saved preferences and waits silently in manual mode. First use defaults to B/crown at 50% volume.

## Sleep and power

Wake the app with a function key. The wake gesture is consumed so it does not also play a tone. After waking, the app returns to manual standby. The independent hardware power key retains the device's normal power behavior.

Sleep reduces activity but does not physically disconnect the battery. Whole-device sleep current and battery runtime have not been measured for this project.
