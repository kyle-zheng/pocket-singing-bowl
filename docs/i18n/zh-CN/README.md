# 口袋颂钵

**一轮满月，一只金色的钵，把片刻宁静放进口袋。**

口袋颂钵（Pocket Singing Bowl）是为 [FoloToy AI Passport](https://github.com/FoloToy/ai-passport) 制作的离线颂钵应用，灵感来自尼泊尔喜马拉雅颂钵。七种原创合成音调，搭配简单的按键操作，为日常放松、专注和冥想提供一个随身的小入口。

## 可以做什么

- 在 C 调海底轮至 B 调顶轮之间选择七种音调与主题。
- 短按播放一声，也可以开启自动颂钵，按自己的节奏聆听余音。
- 敲钵间隔可设为 6～60 秒，自动播放可选定时或不限时。
- 音量可调为 0%～100%，0% 为静音；长按按键可加快调节。
- 可选开启闲置十分钟后自动休眠，并以屏幕渐暗过渡；默认关闭。
- 全程离线，设置会保存。

当前设备界面为简体中文；项目文档默认英文，并提供简体中文入口。上图为 AI 生成的示意图，钵面圆形图案不代表已核实的官方标志或品牌背书。声音为原创合成音色，并非实体颂钵录音；主题和脉轮名称用于组织聆听体验，不宣称医学疗效。

## 开始聆听

1. 将固件安装到 AI Passport，无需配网。可从上方玩法社区进入安装流程；手动刷写请查看[安装指南](INSTALL.md)。
2. 短按确认键播放一声，短按上／下键切换音调与主题。
3. 长按确认键开始自动颂钵，短按暂停或继续，再长按返回手动待机。
4. 双击确认键进入设置。短按上／下键选择或调整，短按确认键进入编辑或保存；长按确认键取消编辑，或从设置列表返回。编辑间隔和音量时，可长按上／下键快速调节。

进入设置会暂停自动颂钵；返回主页后，短按确认键继续。英文说明中的 OK、UP、DOWN 分别对应确认键、上键、下键。

## v0.1.8 默认设置

| 设置 | 默认值 |
| --- | --- |
| 音调 | B 调 · 顶轮 |
| 主题 | 静心 · 冥想 |
| 颂钵音量 | 50% |
| 敲钵间隔 | 6 秒 |
| 自动时长 | 3 分钟 |
| 自动休眠 | 关闭 |
| 开机状态 | 手动待机，不自动发声 |

普通重启会优先读取已保存的设置。完整合并镜像刷写会替换现有应用并恢复默认设置；刷写前请阅读安装说明。

## 开发状态

v0.1.8 已在开发过程中完成编译、校验和设备刷写。它将首次使用的默认音调改为 B 调顶轮、默认音量改为 50%，并保留 v0.1.7 的音频优化。创作者反馈，此前的调音已消除其试听中的爆鸣杂音；这属于实际试听反馈，不等同于完整的声学或续航测量。
