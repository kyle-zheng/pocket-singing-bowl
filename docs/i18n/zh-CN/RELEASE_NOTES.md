# 版本说明

## v0.1.8

- 首次使用默认 **B 调顶轮、50% 音量**。
- 保留 v0.1.7 改进后的音色、音量曲线与叠加控制。
- 普通重启优先读取已保存的设置。

## 首次社区版本之后包含的改进

- 柔化起音并平衡不同音调，减少刺耳感，尤其是低音调。
- 优化声音叠加与输出上限，减少连续播放时的爆鸣杂音。
- 音量仍为 0%～100%，包含可保存的静音，并支持长按上／下键快速调节。
- 改进电量确认与休眠唤醒后的读数恢复。

## 安装与验证

下载包中的完整镜像是此前已编译并刷入设备的 v0.1.8 镜像，SHA-256 为：

```text
345e973c2044f77510625c36e9491ebc21063dfb02b9faea77e0feceb7958d11
```

开发过程中已通过固件构建、主机测试、合并镜像校验和刷写校验；启动日志确认 B 调顶轮、50% 音量。v0.1.7 调音后，我在试听中已听不到之前的爆鸣杂音。我尚未做完整声学测试或整机休眠电流测量。

本次 GitHub 整理提供源码、双语文档与下载资料，不引入新固件版本，也不改变 v0.1.8 的运行行为。
