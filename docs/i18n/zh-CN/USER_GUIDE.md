# 使用方法

口袋颂钵完全离线运行，当前设备界面为简体中文。英文文档中的 OK、UP、DOWN 分别对应确认键、上键、下键。

## 主要按键

| 页面或模式 | 操作 | 功能 |
| --- | --- | --- |
| 主页，手动或自动模式 | 短按上／下键 | 切换音调与主题 |
| 手动模式 | 短按确认键 | 播放一声 |
| 手动模式 | 长按确认键 | 开始自动颂钵，并立即播放一声 |
| 自动模式 | 短按确认键 | 暂停或继续 |
| 自动模式 | 长按确认键 | 结束并返回手动待机 |
| 主页 | 双击确认键 | 进入设置，并暂停自动颂钵 |
| 设置列表 | 短按上／下键 | 选择设置项 |
| 设置列表 | 短按确认键 | 编辑所选设置 |
| 设置列表 | 长按确认键 | 返回主页 |
| 编辑设置 | 短按上／下键 | 调整数值 |
| 编辑设置 | 短按确认键 | 保存 |
| 编辑设置 | 长按确认键 | 取消本次编辑 |
| 编辑间隔或音量 | 长按上／下键 | 加快调节，松开即停 |

离开设置后，自动颂钵保持暂停；回到主页短按确认键可继续。自动模式中也能切换主题。

## 七种主题

| 音调 | 脉轮名称 | 主题 |
| --- | --- | --- |
| C 调 | 海底轮 | 安定 · 放松 |
| D 调 | 脐轮 | 感受 · 流动 |
| E 调 | 太阳轮 | 自信 · 行动 |
| F 调 | 心轮 | 接纳 · 关怀 |
| G 调 | 喉轮 | 表达 · 倾听 |
| A 调 | 眉心轮 | 专注 · 觉察 |
| B 调 | 顶轮 | 静心 · 冥想 |

这些名称用于组织聆听体验，并非医学分类，也不承诺治疗效果。

## 设置

- **敲钵间隔：**6～60 秒，每次调整 1 秒，默认 6 秒。
- **自动时长：**1、3、5、10 分钟或不限时，默认 3 分钟。不限时会持续到你暂停、结束或设备电量耗尽。
- **颂钵音量：**0%～100%，每次调整 5%，默认 50%。0% 为可保存的静音状态，最高档使用本应用调校后的输出上限。
- **自动休眠：**默认关闭。开启后，闲置十分钟会先渐暗屏幕，再进入休眠；自动颂钵正在播放时不会休眠。定时播放结束后会重新开始计算闲置时间。

设置会在短暂的操作停顿后保存。普通重启读取已保存的设置，并安静地进入手动待机。首次使用默认 B 调顶轮、50% 音量。

## 休眠与电源

按功能键可唤醒。唤醒按键不会同时触发播放，唤醒后返回手动待机。独立的硬件电源键保留设备原有的电源行为。

休眠会降低活动，但不会物理断开电池。本项目尚未测量整机休眠电流和续航时间。
